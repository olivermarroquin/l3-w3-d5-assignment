# React Users App

## What this app does

This is a simple multi-page React application built with React Router.

The app has three pages:

- Home page
- Users page
- About page

The Users page fetches data from an external API (DummyJSON) using `useEffect` and displays a list of users.

There is also a button that allows the user to toggle (show/hide) email addresses for each user.

---

## How to run the app

1. Install dependencies:

```bash
npm install
```

2. Install React Router:

```bash
npm install react-router-dom
```

3. Start the development server:

```bash
npm run dev
```

4. Open the app in your browser:
   http://localhost:5173
